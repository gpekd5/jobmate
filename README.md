# JobMate

**JobMate는 이력서와 포트폴리오를 분석하고, 자동으로 수집한 채용공고 중 나에게 맞는 공고를 적합도(%)와 함께 추천하는 AI 취업 도우미 서비스입니다.**

## 어떤 서비스인가요?

채용 사이트마다 공고를 찾아다니고, 자격요건을 이력서와 하나씩 비교하는 시간을 줄여 줍니다.

사용자가 **이력서를 등록**하면 경력·기술·프로젝트 경험을 분석합니다. **포트폴리오, 지원 희망 직무, 희망 근무 지역은 선택**해서 추가할 수 있습니다.

JobMate는 이용이 허용된 채용 데이터 소스에서 공고를 주기적으로 모으고, 가능한 범위에서 **담당업무·필수 지원자격·우대사항**을 구분해 내 경험과 비교합니다.

## 핵심 기능 (구현 예정)

- **이력서·포트폴리오 분석:** 문서의 경력과 기술을 정리하고 사용자가 확인·수정
- **채용공고 자동 수집:** 허용된 채용 사이트의 신규·변경 공고와 상세 요건 확보
- **AI 맞춤 추천:** 자격요건과 내 경험의 일치 정도를 0~100% 적합도로 표현
- **추천 근거 설명:** 일치하는 역량, 부족한 조건, 확인되지 않은 요건을 구분
- **모바일 우선 웹:** 휴대폰과 데스크톱에서 맞춤 공고 확인, 조건 검색, 원문 이동
- **관심 공고·지원 관리:** 유용한 공고를 저장하고 지원 과정을 기록
- **후속 AI 기능:** 기업 정보 조사와 자기소개서 초안 작성

## 이용 흐름

이력서 등록 → AI 경력 분석 및 사용자 확인 → 공고 자동 수집·요건 추출 → 적합도 계산 → 맞춤 공고 추천

**적합도는 채용 요건과의 일치 정도를 나타내는 참고 점수이며 합격 확률은 아닙니다.** 공고의 상세 내용은 제공처가 허용하는 범위에서 수집하고, 확인할 수 없는 정보는 확인되지 않았다고 표시합니다.

> 위 기능은 서비스 목표입니다. 기능별 구현 상태에 따라 실제 제공 범위가 달라질 수 있습니다.
