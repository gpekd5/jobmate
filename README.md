# JobMate

빠르게 실사용할 수 있는 AI 기반 개인 취업 도우미. 채용공고 탐색과 지원 준비를 돕는다.

## 개발 순서

1. Issue #1: 아키텍처·개발 컨벤션·GitHub 템플릿 정립 (현재는 문서만 제공).
2. Issue #2: Java 17 / Spring Boot / Gradle / MySQL / Spring Data JPA와 React / TypeScript / Vite 로컬 실행 환경 구성.
3. 이후 Issue: 로컬에서 실행 가능한 MVP 기능 구현. 운영 배포 방식은 후속 Issue에서 결정.
