# JobMate

**JobMate**는 나에게 맞는 채용공고를 찾고, 비교하고, 지원 과정까지 관리하는 개인 맞춤형 취업 도우미 서비스입니다.

## 서비스 소개

여러 채용 사이트를 반복해서 확인하고, 공고마다 다른 요구사항을 비교하며, 지원 내역을 따로 기록해야 하는 번거로움을 줄이는 것이 목표입니다. 채용공고 정보와 개인의 경력·희망 조건을 한곳에서 연결해 지원 여부를 판단할 수 있도록 돕습니다.

## 주요 기능 (구현 예정)

- **채용공고 수집·검색:** 이용이 허용된 공식 API 등으로 공고를 수집하고 중복·마감 정보를 관리합니다. 저장된 공고를 직무·지역 등 조건으로 검색합니다.
- **맞춤형 공고 추천:** 경력·기술 스택·희망 조건을 바탕으로 적합도와 판단 근거를 제공합니다.
- **기업 정보 분석:** 출처를 확인할 수 있는 공개 정보를 바탕으로 기업과 채용 직무를 파악하도록 돕습니다.
- **관심 공고 및 지원 이력:** 관심 공고와 지원 단계별 진행 상황을 기록합니다.
- **자기소개서 초안:** 사용자가 특정 공고를 선택하고 생성 요청을 했을 때만 작성 초안을 제공합니다.

## 이용 흐름

경력과 희망 조건 입력 → 채용공고 탐색·비교 → 적합도 및 기업 정보 확인 → 지원 준비 → 지원 이력 관리

> 위 기능은 서비스 목표이며, 아직 구현 완료된 기능을 의미하지 않습니다.
